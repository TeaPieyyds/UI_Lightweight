# UI_Lightweight · M3 Canvas Pro+

一个**移动端 Material Design 3 UI 设计工具**，单文件实现（`index.html`，约 238KB / 4900 行），可直接在浏览器或手机上打开使用，**无需构建、无需依赖、无需联网**。用于在手机上可视化拖拽 M3 组件、组织多屏原型、连线交互，并一键导出 AI 提示词。

- 核心源码：[`index.html`](./index.html)
- 许可证：[`LICENSE`](./LICENSE)（**BUSL-1.1**）

|------|------|
| **按钮** | 按钮、图标按钮、悬浮按钮(FAB)、标签、分段按钮、星级评分、加载指示器 |

### 🆕 特殊组件

这几个是画布上的"实体组件"，但同时具备跨屏同步等特殊能力：

#### 🧭 滑动导航栏（导航分组）

- 本身是一个**可选中 / 拖动 / 在图层面板出现**的普通画布组件
- **特殊能力 · 多屏同步**：属性面板勾选其它屏幕后，会在那些屏幕上**镜像显示**（同一份数据，改动自动同步；删除则镜像一起消失）
- **固定停靠**：切屏时导航栏**保持不动**，只有屏幕内容左右滑入（像"固定页签"，切屏动画只作用于内容层）
- **胶囊指示器**：当前选中项用一颗胶囊框包住，切换时**平滑滑动**过去
- **每个动作都有过渡动画**（原地更新 DOM，不重建整层，动画连续不闪断）
- 图标可**上传自定义图片**（表情符号或图片 URL）

#### 🏷️ 标题（导航分组）

- 显示在**屏幕顶部**的固定标题栏，同样支持**多屏同步**
- **6 种样式**：实心 `solid` / 描边 `outline` / 玻璃 `glass` / 渐变 `gradient` / 悬浮 `elevated` / 无底 `plain`
- 文字 + 副标题（可选）+ 左侧图标（可选）
- 支持**文字对齐**（左 / 中 / 右）、**字号滑条**（10~40px）、主色自定义
- **吸顶**按钮：一键贴到屏幕顶部
- 文字输入**原地刷新**（不失焦、不卡顿）

#### 📜 滚动页面（媒体分组）

- 类似「滑动窗体」，但是**单一页面**，内容可**一直向下延伸**
- **双击进入内容编辑**，往里放任意组件
- 编辑时画布会**自动延展到内容高度**，组件可拖到下方、页面可**纵向滚动**
- 带**可见滑条**（主题色，6px）
- **预览时可原生滑动**，页面内的子组件（按钮等）也**可以正常点击**

### 🎨 材质效果

- **玻璃 (glass)**：模糊 + 噪点纹理 + 高光描边，参数可调
- **液体 (liquid)**：多向流光渐变 + 高光扫动动画，参数可调

### ⚡ 交互与编排

- **浮动工具栏**：选中组件上方出现，支持 复制 / 置顶 / 置底 / 删除
- **多选模式**：可同时选中多个组件（橙色高亮），批量操作
- **批量复制 / 粘贴**：多选复制 → 切屏 → **长按画布粘贴**（一次性，保持相对位置，粘贴后清空）
- **锁定 / 隐藏**：组件可上锁（🔒）或隐藏，预览时自动处理
- **组件连线 / 联动**：`link-layer` 连线模式，组件间可建立交互关系，支持编辑/删除连线
- **导航联动**：`setNavLink` 把按钮/图标指向目标屏幕，预览时点击跳转
- **画布网格 + 吸附**：网格开关 + 吸附强度可调（"开放"档 = 不吸附，随意放置）
- **缩放控制**：画布可缩放（`zoomIn` / `zoomOut` / `applyZoom`）
- **模板库 / 资源库**：一键套用模板与资源（`showTemplates` / `showResources` / `useResource`）
- **整理 (Tidy)**：一键整理画布布局
- **左侧组件库侧边栏**：搜索 + 分组 + 一键添加
- **右侧属性面板**：搜索、手风琴分组、对齐网格、图标搜索
- **卡片文字排版**：卡片内文字可调**字号**与**对齐（水平/垂直）**，注释保持不变
- **画布页面编辑**：页面尺寸/背景在线调整
- **双击内联编辑**：所有 `data-field` 标记的文字可就地编辑
- **可交互状态组件**：滑块、星级、复选框、单选框、开关、分段、标签、标签页、底部导航、手风琴、轮播、折叠列表 均可直接在画布上点选/拖动
- **对齐辅助线**：拖拽时显示红色十字准星
- **预览模式**：隐藏所有 UI 工具栏，模拟真实 App 跳转体验（画布放得下时居中，放不下时可上下滚动）
- **撤销/重做**：顶栏，40 步历史
- **本地存档**：自动保存到 `localStorage`，刷新后恢复
- **JSON 导入 / 导出**：工程可导出为 JSON 备份、再导入（`exportJSON` / `importJSON`）

## 🚀 使用

1. 打开 / 部署 `index.html`（直接双击或用浏览器打开即可，也可托管到任意静态服务）
2. 左侧侧边栏选组件 → 拖拽定位 → 点选编辑
3. 右侧属性面板精调 / 多选 / 锁定 / 隐藏 / 连线
4. 缩放画布、切换多屏、套用模板
5. 点"导出"生成提示词，或导出 JSON 备份

### 小技巧

- **双击**组件 → 就地编辑文字
- **双击**滚动页面 / 滑动窗体 / 折叠列表 → 进入内容编辑
- **长按**组件 → 呼出菜单（复制 / 删除 / 置顶 / 完整属性 / 锁定 / 隐藏）
- **长按**画布空白处 → 粘贴剪贴板内容
- 顶部「▶ 运行」进入**预览模式**，体验真实跳转

## 🛠 技术说明

- **单文件架构**：全部 HTML + CSS + JS 内联在一个 `index.html` 中，方便分享与部署
- **零依赖**：不使用任何框架或外部库
- **持久化**：`localStorage` 自动存档 + JSON 手动导入导出
- **移动优先**：针对触屏操作优化（touch 事件、长按、双击、原生滚动放行）
- **兼容性**：现代浏览器 / Android WebView
