# UI_Lightweight · M3 Canvas Pro+

一个**移动端 Material Design 3 UI 设计工具**，单文件实现（`index.html`，约 148KB），可直接在浏览器/手机上打开使用，无需构建。用于在手机上可视化拖拽 M3 组件、组织多屏原型，并一键导出 AI 提示词。

- 核心源码：[`index.html`](./index.html)
- 许可证：[`LICENSE`](./LICENSE)（**BUSL-1.1**）

## ✨ 功能总览

### 🧩 组件库（39 种）

| 分组 | 组件 |
|------|------|
| **按钮类** | 按钮、图标按钮、悬浮按钮(FAB)、标签、分段、星级评分 |
| **输入类** | 输入框、搜索栏、复选框、单选框、开关、滑块 |
| **展示类** | 卡片、列表项、头像、徽章、图片、进度条、骨架屏、横幅、分割线、文本、**轮播图**、**视频**、**手风琴**、**时间线**、**环形图**、**统计卡**、**加载动画** |
| **导航类** | 应用栏、标签页、底部导航、**页内视图(PageView)** |
| **容器/反馈** | 容器、对话框、消息条(Snackbar) |

> 相比上一版（28 种）新增：轮播图、视频、手风琴、时间线、环形图、统计卡、加载动画、页内视图、图片直接上传等。

### 🎨 材质效果

- **玻璃 (glass)**：模糊 + 噪点纹理 + 高光描边，参数可调
- **液体 (liquid)**：多向流光渐变 + 高光扫动动画，参数可调

### ⚡ 交互特性

- **浮动工具栏**：选中组件上方出现，支持 复制 / 置顶 / 置底 / 删除
- **多选模式**：可同时选中多个组件（橙色高亮），批量操作
- **锁定 / 隐藏**：组件可上锁（🔒）或隐藏，预览时自动处理
- **左侧组件库侧边栏**：搜索 + 分组 + 一键添加
- **右侧属性面板**：搜索、手风琴分组、对齐网格、图标搜索
- **缩放控制**：画布可缩放（`--canvas-w / --canvas-h` 变量化）
- **画布页面编辑**：页面尺寸/背景在线调整
- **双击内联编辑**：所有 `data-field` 标记的文字可就地编辑
- **可交互状态组件**：滑块、星级、复选框、单选框、开关、分段、标签、标签页、底部导航、手风琴、轮播 均可直接在画布上点选/拖动
- **对齐辅助线**：拖拽时显示红色十字准星
- **预览模式**：隐藏所有 UI 工具栏，模拟真实 App 跳转体验
- **撤销/重做**：顶栏，40 步历史
- **本地存档**：自动保存到 `localStorage`，刷新后恢复

### 📋 主题与导出

- 12 预设色板 + 自定义主色
- 圆角风格切换（圆角 / 直角 / 全圆）
- 字体切换（Roboto / Roboto Flex / Roboto Serif / 系统）
- 画布背景（纯白 / 彩色渐变）
- **AI 提示词导出**：一键生成可复制的设计描述

## 🚀 使用

1. 打开 / 部署 `index.html`
2. 左侧侧边栏选组件 → 拖拽定位 → 点选编辑
3. 右侧属性面板精调 / 多选 / 锁定 / 隐藏
4. 缩放画布、切换多屏
5. 点"导出"生成提示词复制给 AI
